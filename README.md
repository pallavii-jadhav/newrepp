project overview -
Event Booking System

Event Booking System is a web-based application designed to simplify and automate the process of booking venues and halls for various events. The system provides an easy-to-use platform where customers can explore available venues, check hall details and availability, select required services, and make bookings online.

Key Features:-
User Registration & Login
Venue and Hall Management
Hall Availability Checking
Online Event Booking
Event and Customer Details Management
Additional Service Selection
Payment Management

Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Development Tools: VS Code

System Modules:-
User Module--
Users can create an account, log in securely, browse available venues and halls, check availability, select required services, make bookings, view booking details, and provide feedback.
Admin Module--
Administrators can manage users, venues, halls, services, bookings, payments, and feedback. The admin module provides better control and monitoring of the overall system.

The primary objective of the Event Booking System is to provide a user-friendly, efficient, and centralized platform for event venue booking and management.
